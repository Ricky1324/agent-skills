# 系统优化简历

请帮我系统修改这份简历，目标是用于【填写目标岗位，例如：AI 应用开发 / Agent 开发 / 数据分析 / 软件开发】岗位投递。

请不要只做表面措辞润色，而是从招聘者视角整体审视这份简历，包括：

1. 判断当前简历中哪些经历最值得保留、强化或删减。
2. 优化项目和实习经历的表达，让每一条尽量体现：
   - 做了什么；
   - 解决了什么问题；
   - 使用了什么技术或方法；
   - 最终产生了什么结果或价值。
3. 避免流水账、学生作业感、过度包装和空泛表达。
4. 可以适当重组内容顺序、合并重复信息、调整项目名称和 bullet 结构。
5. 技术描述要专业，但不要为了显得高级而堆砌术语。
6. 对 AI / RAG / Agent / 数据处理相关经历，重点突出系统设计、数据流程、检索、评估、工程实现和实际业务场景。
7. 对于竞争力相对较弱的经历，请优先从内容取舍、项目定位、表达角度和与目标岗位的关联性上进行优化；如果确实不适合保留，再说明原因并建议删减或替换。
8. 可以根据我提供的真实经历，对内容进行适度抽象、归纳和职业化表达，不要求完全沿用我的原始措辞。对于可以从现有信息合理推导出的职责、技术实现或项目价值，可以帮助我提炼。
9. 对于我确实做过、但目前描述不够完整的内容，可以根据我提供的信息帮助我重新组织和表达。
10. 如果某个数据或成果值得量化但目前缺失，请标记为“建议补充并给出可能合理的数字”。

## 事实边界

- 可以职业化提炼已有信息；如果某项推导需要我确认，请明确标记为“需确认”。
- “建议补充并给出可能合理的数字”仅用于提示我核实和补充，不得将猜测数字直接写成既成事实。

## 输出方式

### 第一部分：整体评价

先整体评价这段描述或这份简历目前最大的问题，以及它和目标岗位之间的匹配度。

### 第二部分：逐段修改

逐段修改，说明每一段为什么要改，并给出修改后的版本。

### 第三部分：最终投递版本

给我一版可以直接用于投递的最终版本，语言简洁、专业、自然，避免明显的 AI 生成痕迹。

### 第四部分：后续增强建议

指出还有哪些地方，如果我补充更多信息或者进一步升级项目，可以进一步增强简历。
